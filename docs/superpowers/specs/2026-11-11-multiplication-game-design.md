# 구구단 연습 게임 설계 사양서 (Spec)

## 1. 개요 및 대상 사용자
- **대상**: 초등학교 2학년 학생 (구구단 기초 학습자)
- **목적**: 2단부터 9단까지의 곱셈구구를 5초 제한시간 동안 직관적이고 재미있게 연습할 수 있는 반응형 웹 애플리케이션
- **형태**: 단일 웹 앱 (`index.html`, `style.css`, `app.js`)으로 별도 설치 없이 브라우저에서 바로 더블 클릭으로 실행 가능

---

## 2. 주요 기능 및 요구사항 매핑

| 기능 요구사항 | 상세 동작 및 구현 내용 |
|---|---|
| **랜덤 문제 출제** | 2단부터 9단 중 랜덤 문제 1개 생성 (예: $7 \times 8 = ?$). 연속으로 동일 문제가 나오지 않도록 방지 |
| **5초 제한시간 타이머** | 문제가 제시되자마자 5.0초 카운트다운 시작. 애니메이션 프로그레스 바(녹색→주황→빨강)와 대형 숫자(5.0초) 표시 |
| **답안 입력 및 제출** | 숫자 입력 필드 + '확인' 버튼 + 키보드 Enter 키 지원. 숫자 키패드 지원 (`inputmode="numeric"`) |
| **정답 피드백** | 대형 텍스트로 **"🎉 정답!"** 표시, 통통 튀는 애니메이션 및 경쾌한 팡파레 사운드(Web Audio API 자체 생성) |
| **오답 피드백** | **"아쉬워요! 정답은 [답]이에요."** 안내 문구 크게 표시 및 흔들림 애니메이션 |
| **시간 초과 처리** | 5초 경과 시 **"⏰ 시간 초과! 아쉬워요! 정답은 [답]이에요."** 표시 |
| **진행 흐름 (다음 문제)** | 피드백 표시 후 약 1.5초 뒤 자동으로 다음 문제 출제 (또는 '다음 문제' 버튼 지원) |
| **학습 격려 요소** | 연속 정답(콤보), 푼 문제 수, 맞힌 개수 스코어보드 제공 |

---

## 3. UI/UX 디자인 (초등 2학년 맞춤형)
1. **서체 및 버튼**: 큼직하고 둥글둥글한 폰트, 눈에 잘 띄는 귀여운 파스텔톤 컬러(스카이블루, 옐로우, 코랄핑크).
2. **시각적 타이머**: 숫자 카운트다운뿐만 아니라 직관적으로 줄어드는 시계/타이머 게이지 바.
3. **접근성 및 조작성**: 마우스 클릭뿐 아니라 키보드 숫자 입력 후 `Enter`만 눌러도 제출되도록 하여 빠른 반응 유도.
